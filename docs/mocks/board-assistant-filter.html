What this study settles

  • The filter sits between the sprint summary and the columns. The summary keeps describing the whole sprint; only the columns narrow.
  • The choices are All assistants, then every assistant who owns a story on this board in name order, then Unassigned when any story has no owner. Each choice shows how many stories it would leave.
  • Column counts and empty states follow the filter. A narrowed board says how many of the sprint’s stories it is showing and offers one action to show them all again.
  • The choice is held in the address (/board?assistant={assistant id}, or ?assistant=unassigned; this study uses names for readability) so a refresh or a shared link keeps it. An unknown assistant in the address falls back to all stories.
  • Moving a story, or editing it, keeps the current filter.
