# User journeys

User journeys the app implements, ordered by value to the app. Each maps to a
feature in [`detailed-designs/`](detailed-designs/); effort comes from
[`estimates/`](estimates/).

| #   | Journey                           | Description                                                | Effort |
| --- | --------------------------------- | ---------------------------------------------------------- | ------ |
| 1   | Execute active sprint             | Move stories across the board to deliver sprint work.      | 5 days |
| 2   | Plan two-week sprints             | Commit groomed stories to a sprint with a clear goal.      | 5 days |
| 3   | Groom backlog                     | Refine stories until they are estimated and ready.         | 4 days |
| 4   | Manage stories and tasks          | Create, edit, and break stories into trackable tasks.      | 5 days |
| 5   | Manage work hierarchy             | Organise initiatives, epics, and stories into a structure. | 4 days |
| 6   | Log hours against a story         | Record assistant time spent on delivering a story.         | 4 days |
| 7   | Manage assistants and assignments | Maintain assistants and assign them to stories.            | 3 days |
| 8   | Filter board by assistant         | Focus the sprint board on one assistant's work.            | 3 days |
| 9   | Navigate workspace                | Move between boards, backlog, and planning screens.        | 3 days |
| 10  | Gate workspace access             | Enter the workspace using the shared passcode.             | 4 days |
| 11  | Edit initiative brief             | Capture an initiative's goals and context.                 | 5 days |
| 12  | Edit epic summary                 | Describe an epic's purpose and scope.                      | 3 days |
| 13  | Attach files to a work item       | Keep supporting documents with the work they explain.      | 5 days |
