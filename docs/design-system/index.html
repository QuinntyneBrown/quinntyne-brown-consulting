How to use

  • Link tokens/tokens.css then assets/components.css.
  • Use the class names from each component's Code section; states come from real attributes (disabled, aria-*).
  • Consume tokens/tokens.json (DTCG) to generate platform constants.
  • Set data-theme="dark" on <html> to force dark; otherwise the OS preference applies.
