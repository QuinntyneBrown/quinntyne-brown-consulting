Iconography

Overview

  • The mocks used text glyphs (▦ ≡ ⌘ ◎ × ✓); the system replaces them with inline SVG so they scale, theme and align.
  • Icons inherit text colour.

Sizes

PartTokenLightDark
Small: inline with captions, chips--icon-size-sm
Medium: buttons, nav--icon-size-md
Large: empty states, drop zone--icon-size-lg

Usage

  • <svg class="icon" aria-hidden="true" viewBox="0 0 24 24">; the control around it carries the name.
  • Pair status icons with words.
  • One icon per action across the product (edit is always the pencil).

Accessibility

  • Decorative icons are aria-hidden.
  • Meaningful standalone icons have role="img" and a label.
  • Icon-only buttons have aria-label and a tooltip.
