Foundation

Motion

Short, purposeful transitions; all of them collapse under reduced motion.

WCAG 2.2 AAStatus: stable
  • Overview
  • Durations
  • Easing
  • Choreography
  • Accessibility: reduced motion
  • Tokens

Overview

  • Hover and colour: --duration-fast.
  • Menus, toasts, page enter, drawer: --duration-base (the mocks' 180–200ms).
  • Progress fill: --duration-slow.
  • Passcode shake, spinner cycle: --duration-deliberate (the mocks' 460ms).

Durations

Select Play to run each transition; under reduced motion the dot jumps.

Easing

PartTokenLightDark
Ease standard--ease-standard

Ease exit--ease-exit
Ease spring--ease-spring

Choreography

  • Things enter with --ease-enter and leave faster with --ease-exit.
  • Move 4–8px at most; no bounces except the passcode error shake.

Accessibility: reduced motion

  • Under prefers-reduced-motion: reduce the tokens set every duration to 0.01ms, so components need no media queries.
  • Shimmer, indeterminate sweep and the shake are switched off explicitly; spinners keep turning as status.
  • Nothing flashes more than three times a second.
