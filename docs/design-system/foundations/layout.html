Layout

Sidebar shell, responsive columns, gutters and margins, and the breakpoints the mocks already used (760, 1000, 1180px).

WCAG 2.2 AAStatus: stable
  • Overview
  • Breakpoints
  • Columns, gutters, margins
  • Page templates
  • Usage
  • Tokens

Overview

  • Desktop: 224px fixed sidebar, 80px sticky top bar, content up to 1440px.
  • Phones: sidebar becomes a drawer, top bar compacts to 72px.

Breakpoints

TokenValueWhat changes
--layout-breakpoint-smLarge phones: inline forms go two-up.
--layout-breakpoint-mdSidebar fixed, top bar full, form grid two columns, data rows become rows.
--layout-breakpoint-lgBoard shows three columns; data rows show all cells.
--layout-breakpoint-xlHours page shows its side panel.
--layout-breakpoint-2xlContent stops growing.

Resize the window: the column count, gutter and margin follow --layout-columns, --layout-gutter and --layout-margin.

Page templates

  • Shell: sidebar + top bar + container (board, backlog, hierarchy, assistants, hours).
  • Auth: centred panel, no shell (passcode).
  • Editor: shell with a two-pane write/preview body (initiative editor).
  • Detail: shell with a page head, stats and lists (assistant hours).

Usage

  • Pages use .container; never set page margins by hand.
  • Prose is capped at --layout-measure.
