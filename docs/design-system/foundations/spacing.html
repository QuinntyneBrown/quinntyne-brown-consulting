Spacing

A 4px scale. The mocks' 2–11px and 13–30px values snap onto it.

WCAG 2.2 AAStatus: stable
  • Overview
  • Scale
  • Inside and between
  • Control heights

Overview

  • Every margin, padding and gap is a --space-* token.
  • The name is the multiple of 4px: --space-6 = 24px; --space-1-5 = 6px is the one half-step, kept because the mocks used 5–7px gaps 48 times.

Inside and between

  • Inside components: ≤ --space-6 (button padding 16px, card padding 24px).
  • Between components in a group: --space-2 to --space-5 (card stack 12px, board gap 20px).
  • Between page blocks: ≥ --space-8 (page head 40px, page top 48px).

Control heights

PartTokenLightDark
Small: card and row actions--control-height-sm
Medium: buttons and inputs--control-height-md
Large: passcode, auth--control-height-lg

Usage

  • Padding by size: small controls --space-3, medium --space-4, large --space-6.
  • Dialogs: head and body --space-6, phones --space-5.
  • Never use raw px for spacing in components.
