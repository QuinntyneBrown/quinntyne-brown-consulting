Foundation

Elevation

Four shadows and three surface steps, plus the z-order every overlay uses.

WCAG 2.2 AAStatus: stable
  • Overview
  • Shadows
  • Surface hierarchy
  • Z-order
  • Usage
  • Tokens

Overview

  • The mocks had two shadows (card 0 2px 3px at 2.5%, overlay 0 18px 50px at 12%); the system adds two steps between them.
  • In dark mode surfaces get lighter as they rise, and shadows get darker.

Shadows

--shadow-1Story cards
--shadow-2Hovered cards
--shadow-3Menus, auth panel
--shadow-4Dialogs, toasts, drawer

Usage

  • Components never set a raw z-index.
  • Use a border, not a shadow, to separate flat cards.
