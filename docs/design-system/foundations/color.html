Color

A green-tinted neutral ramp, the QBC brand green, and three status hues, mapped to roles that both themes redefine.

Overview

  • Primitives (--palette-*) come straight from the mocks' --qbc-* values; only semantic tokens read them.
  • Components use roles: --color-bg-*, --color-fg-*, --color-border-*, --color-accent* and the four status families.
  • Every pairing a component relies on is listed in tokens/contrast-pairs.json and checked in both themes.

Usage

  • Text on surfaces: --color-fg-default, secondary --color-fg-muted, metadata and placeholders --color-fg-subtle.
  • One accent: buttons, links, current nav, selected states, focus ring.
  • Status colour always pairs with an icon or a word.
  • Never reference a --palette-* token from a component.

Adding a brand theme

[data-theme="partner"] {
  --color-accent: var(--palette-blue-600);
  --color-accent-hover: var(--palette-blue-700);
  --color-fg-accent: var(--palette-blue-700);
  --color-focus-ring: var(--palette-blue-600);
}

Override semantic tokens only, then add the new pairs to contrast-pairs.json and run check_contrast.py.
