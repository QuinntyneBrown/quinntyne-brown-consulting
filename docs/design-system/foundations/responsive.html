Responsive

Mobile-first rules for every breakpoint, taken from the mocks' 760 and 1000px media queries.

WCAG 2.2 AAStatus: stable
  • Overview
  • Breakpoint behaviours
  • Touch

Overview

  • Build for 360px first, then enhance at 760 and 1000px.
  • No horizontal scroll at 320px except inside tables and tab lists.

Touch

  • Targets ≥ 24px, comfortable 44px (nav items, passcode boxes).
  • Drag and drop has button alternatives.
  • No hover-only information.

Testing matrix

  • Widths: 320, 360, 768, 1024, 1280, 1440px.
  • Both themes at 360 and 1280.
  • 200% zoom at 1280 (reflow).
