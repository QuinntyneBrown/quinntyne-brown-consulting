Toast

A brief message after an action: story saved, sprint started, upload failed.

WCAG 2.2 AAStatus: stableNative HTML

Overview

  • Confirms an action the person just took, bottom-right.
  • Success toasts auto-dismiss after 5s (paused on hover/focus); error toasts stay until dismissed.
  • Never for information the person must act on later; use an alert.

Anatomy

  1. IconTone.
  2. MessageOne sentence.
  3. Action (optional)Undo / View / Retry.
  4. Dismiss24px.

Responsive behaviour

  • Below 760px the region spans the bottom edge with 16px margins.

Theming

The component reads semantic tokens only (listed under Tokens). The dark theme re-maps those tokens; nothing in the component changes.

Accessibility

Role and pattern

A persistent role="status" region (polite) in the DOM from page load; error toasts use role="alert". Timers pause on hover and focus (WCAG 2.2.1).

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EscDismisses the focused toast.

Focus

Toasts never take focus; their action buttons are reachable.

Labelling

Dismiss is named "Dismiss".

Contrast

Toast text
Danger toast text

Motion

Rises over --duration-base; reduced motion fades only.

Touch

Controls are at least --control-height-md (40px) tall, above the 24px minimum; in dense rows the whole row is also a target and neighbours keep 8px apart.

Content

  • Past tense, object first: "Story saved.", "Sprint 2 started."
  • Errors say what failed and offer Retry.
