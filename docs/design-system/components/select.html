Select

Choose one value from a list: epic, assistant, sprint, priority.

Overview

  • Native <select> by default; it is accessible and works on phones.
  • Use a radio group for 2-4 visible options, a segmented control for views.

Anatomy

  1. LabelNoun.
  2. ControlNative select, 40px, chevron by the platform.

Variants

Filter (toolbar) and with placeholder option.
HTML
<select class="select" style="width: 12rem;" aria-label="Filter by assistant"><option>All assistants</option><option>Vanessa</option></select><select class="select" style="width: 12rem;" aria-label="Priority"><option value="">Choose priority</option><option>High</option></select>

Sizes

32 / 40 / 48px.
HTML
<select class="select select--sm" style="width: 10rem;" aria-label="Small"><option>Small</option></select><select class="select" style="width: 10rem;" aria-label="Medium"><option>Medium</option></select><select class="select select--lg" style="width: 10rem;" aria-label="Large"><option>Large</option></select>

States

Pointer and focus states are forced with data-state so they can be reviewed statically; product code gets them from real pseudo-classes and attributes.

Both themes

Responsive behaviour

  • Toolbar filters keep a 150px minimum and stack full-width below 760px.

Theming

Component tokens: --field-bg, --field-border, --field-height. Each aliases a semantic token, so a theme re-colours the component by overriding semantic tokens and a product re-skin overrides the component tokens; neither edits the component CSS.

Accessibility

Role and pattern

Native <select>; custom listboxes only when native cannot do the job, then APG Listbox.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
↑ ↓Changes the value.
Alt+↓Opens the list.

Focus

The shared ring (--focus-ring-width solid --color-focus-ring, --focus-ring-offset gap) appears on :focus-visible only. The mocks drew a 25% green halo (rgba(39,103,73,.25)) that measured 1.3:1; the system ring is solid and passes 3:1 (drift D2).

Labelling

Visible label, or aria-label on toolbar filters ("Filter by assistant").

Contrast

Value
Border

Motion

No motion beyond colour transitions over --duration-fast, which the tokens zero under prefers-reduced-motion.

Touch

Controls are at least --control-height-md (40px) tall, above the 24px minimum; in dense rows the whole row is also a target and neighbours keep 8px apart.

Content

  • Placeholder option reads "Choose …" and is not a valid value.
  • "Unassigned" is a real option for assistant pickers.
