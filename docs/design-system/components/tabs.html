Tabs

Switch between panels of one object, like a story's Details, Tasks, Time and Files.

WCAG 2.2 AAStatus: stableNative HTML

Overview

  • Panels are siblings; only one shows.
  • Use the segmented control for two views of the same content, sub-pages for separate URLs.

Anatomy

  1. Selected tabAccent text and 2px underline.
  2. TabMuted text.

Responsive behaviour

  • The tablist scrolls horizontally on phones; it never wraps.

Theming

The component reads semantic tokens only (listed under Tokens). The dark theme re-maps those tokens; nothing in the component changes.

Accessibility

Role and pattern

APG Tabs with automatic activation: role="tablist", tab with aria-selected and aria-controls, tabpanel with aria-labelledby.

Keyboard

KeyAction
TabInto the selected tab, then into the panel.
← →Moves and activates.
Home / EndFirst / last tab.

Focus

The shared ring (--focus-ring-width solid --color-focus-ring, --focus-ring-offset gap) appears on :focus-visible only. The mocks drew a 25% green halo (rgba(39,103,73,.25)) that measured 1.3:1; the system ring is solid and passes 3:1 (drift D2).

Labelling

The tablist is labelled by its object.

Motion

No motion beyond colour transitions over --duration-fast, which the tokens zero under prefers-reduced-motion.

Touch

Controls are at least --control-height-md (40px) tall, above the 24px minimum; in dense rows the whole row is also a target and neighbours keep 8px apart.

Content

  • One or two words; counts in a badge, not the label.
