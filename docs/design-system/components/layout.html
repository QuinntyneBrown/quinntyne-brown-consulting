Layout primitives

Container, grid, stack, cluster and page head: the building blocks every page uses.

Overview

  • Container caps content at 1440px and applies the page margin.
  • Grid uses the responsive column count and gutter.
  • Stack spaces children vertically; cluster wraps them horizontally.
  • Page head pairs the title and lead with page actions.

Anatomy

  1. EyebrowContext.
  2. TitleFluid 30–42px.
  3. LeadMuted, max 72ch.
  4. ActionsCluster, wraps under on phones.

Responsive behaviour

  • Columns 4 / 8 / 12 at <760, 760–999, ≥1000px; gutters 16 / 20 / 24px; margins 16 / 32 / 48px. See Layout.

Theming

The component reads semantic tokens only (listed under Tokens). The dark theme re-maps those tokens; nothing in the component changes.

Accessibility

Role and pattern

Visual order matches DOM order; never reorder with CSS order in a way that breaks reading order.

Motion

No motion beyond colour transitions over --duration-fast, which the tokens zero under prefers-reduced-motion.

Touch

Controls are at least --control-height-md (40px) tall, above the 24px minimum; in dense rows the whole row is also a target and neighbours keep 8px apart.

Content

  • Page titles are nouns: "Board", "Backlog".
