Menu

A menu button opens a short list of actions for one object, such as a story's More actions.

WCAG 2.2 AAStatus: stableAPG Menu Button

Overview

  • Use when a row or card has more than two actions and space is tight.
  • Put the most common action outside the menu as a button.
  • Use a select to choose a value; a menu runs commands.

Anatomy

  1. Item icon16px, optional, aligned for all items.
  2. Item labelVerb phrase.
  3. SeparatorGroups destructive items last.
  4. Danger item--color-danger-fg.

Variants

  • Story
Section label, shortcut, checkable item, disabled item, danger item.
HTML
<ul class="menu" role="menu" aria-label="Story actions"><li class="menu__label" role="presentation">Story</li><li role="none"><button class="menu__item" role="menuitem" type="button">Edit<kbd>E</kbd></button></li><li role="none"><button class="menu__item" role="menuitemcheckbox" aria-checked="true" type="button">Ready for sprint</button></li><li role="none"><button class="menu__item" role="menuitem" type="button" aria-disabled="true">Archive</button></li><li role="separator" class="menu__sep"></li><li role="none"><button class="menu__item menu__item--danger" role="menuitem" type="button">Delete story</button></li></ul>

Sizes

Not applicable: Menu items have one height (--control-height-sm).

States

Pointer and focus states are forced with data-state so they can be reviewed statically; product code gets them from real pseudo-classes and attributes.

Both themes

Responsive behaviour

  • Opens below the trigger; flips above when there is no room.
  • Below 760px a menu with more than six items opens as a bottom sheet (dialog sheet variant).

Theming

The component reads semantic tokens only (listed under Tokens). The dark theme re-maps those tokens; nothing in the component changes.

Accessibility

Role and pattern

APG Menu Button: the trigger has aria-haspopup="menu" and aria-expanded; the list is role="menu" with menuitem, menuitemcheckbox children.

Keyboard

KeyAction
Enter, Space, ↓On the trigger: opens and focuses the first item.
↑ ↓Moves between items, wrapping.
Home / EndFirst / last item.
Letter keysType-ahead to the next matching item.
EscCloses and returns focus to the trigger.
TabCloses and moves on.

Focus

Focus moves into the menu on open; the focused item shows an inset ring and the subtle background.

Labelling

The trigger is labelled with the object ("More actions for QBC-269"); the menu takes aria-label from it.

Contrast

Item on menu
Danger item
Shortcut

Motion

Fades in over --duration-base; reduced motion shows it instantly.

Touch

Controls are at least --control-height-md (40px) tall, above the 24px minimum; in dense rows the whole row is also a target and neighbours keep 8px apart.

Content

  • Verb-first labels.
  • Destructive items last, after a separator.
