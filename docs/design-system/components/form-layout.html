Form layout

How fields arrange in dialogs and pages: two columns on wide screens, one on phones, actions last.

WCAG 2.2 AAStatus: stableNative HTML

Overview

  • Dialog forms use the two-column grid; full-width fields span both.
  • Inline forms add a row (task, time entry) in one line.
  • An error summary appears at the top when submission fails on more than one field.

Anatomy

  1. Grid2 columns, --space-5 rows, --space-4 columns.
  2. Full-width field.field--full.
  3. Actions barRight-aligned, primary last.

Variants

Error summary

Fix 2 problems to save the story
  • Enter a title
  • Choose points
Links jump to each field.
HTML
<div class="error-summary" role="alert" style="width: 26rem;"><strong>Fix 2 problems to save the story</strong><ul><li><a href="#fl3">Enter a title</a></li><li><a href="#fl2">Choose points</a></li></ul></div>

Inline

Add-a-row forms (time entries, tasks).
HTML
<form class="form-inline" onsubmit="return false"><div class="field"><label class="field__label" for="fi1">Date</label><input class="input input--sm" id="fi1" type="date"></div><div class="field"><label class="field__label" for="fi2">Hours</label><input class="input input--sm" id="fi2" style="width: 6rem;"></div><button class="btn btn--primary btn--sm" type="submit">Log time</button></form>

Sizes

Not applicable: The grid has one density.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; product code gets them from real pseudo-classes and attributes.

Submitting: the submit button shows loading, Cancel disables, fields stay editable until the response.

Both themes

Responsive behaviour

  • One column below 760px; actions stay right-aligned and wrap.
  • Inline forms stack to one column on phones.

Theming

The component reads semantic tokens only (listed under Tokens). The dark theme re-maps those tokens; nothing in the component changes.

Accessibility

Role and pattern

<form novalidate> with custom messages; the error summary is role="alert", receives focus on failed submit, and links to fields.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterIn a single-line input: submits the form.

Focus

On a failed submit focus moves to the error summary; on success the dialog closes and focus returns to the trigger.

Labelling

Group related fields with <fieldset> + <legend>.

Contrast

Summary text

Motion

No motion beyond colour transitions over --duration-fast, which the tokens zero under prefers-reduced-motion.

Touch

Controls are at least --control-height-md (40px) tall, above the 24px minimum; in dense rows the whole row is also a target and neighbours keep 8px apart.

Content

  • Summary title counts the problems: "Fix 2 problems to save the story".
