Checkbox

Turn an option on or off, or mark a task done.

WCAG 2.2 AAStatus: stableNative HTML

Overview

  • Single checkboxes confirm or toggle one thing (task done).
  • Groups pick several options; wrap them in a <fieldset>.
  • For a setting that applies immediately, use a switch.

Anatomy

  1. Box18px native input, accent-color.
  2. LabelClicking it toggles the box.
  3. Description (optional)Caption.

Sizes

Not applicable: One size (18px box, 24px target with label).

States

Pointer and focus states are forced with data-state so they can be reviewed statically; product code gets them from real pseudo-classes and attributes.

Responsive behaviour

  • Labels wrap under themselves, never under the box.

Theming

The component reads semantic tokens only (listed under Tokens). The dark theme re-maps those tokens; nothing in the component changes.

Accessibility

Role and pattern

Native <input type="checkbox"> inside its <label>; groups in <fieldset> with <legend>.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
SpaceToggles.

Focus

The shared ring (--focus-ring-width solid --color-focus-ring, --focus-ring-offset gap) appears on :focus-visible only. The mocks drew a 25% green halo (rgba(39,103,73,.25)) that measured 1.3:1; the system ring is solid and passes 3:1 (drift D2).

Labelling

The label names the option; the legend names the group.

Contrast

Label
Box edge (unchecked)
Checked fill

Motion

No motion beyond colour transitions over --duration-fast, which the tokens zero under prefers-reduced-motion.

Touch

The label is part of the target, so the 18px box still gives a 24px+ target.

Content

  • Labels describe the state when checked: "Ready for sprint".
