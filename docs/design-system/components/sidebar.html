Responsive behaviour

  • Below 760px the sidebar slides in from the left over the page (--z-dropdown, --shadow-4), opened by the top bar's menu button and closed by Esc or the scrim.
  • Workspace content drops its 224px margin.

Theming

The component reads semantic tokens only (listed under Tokens). The dark theme re-maps those tokens; nothing in the component changes.

Accessibility

Role and pattern

<nav aria-label="Workspace"> with a list of links; the current one has aria-current="page". As a drawer it behaves like a modal dialog: focus moves in, Esc closes, focus returns to the menu button.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EscDrawer only: closes.

Focus

The shared ring (--focus-ring-width solid --color-focus-ring, --focus-ring-offset gap) appears on :focus-visible only. The mocks drew a 25% green halo (rgba(39,103,73,.25)) that measured 1.3:1; the system ring is solid and passes 3:1 (drift D2).
