Progress bar

Shows how far something has got: sprint completion, upload progress.

WCAG 2.2 AAStatus: stableNative HTML
  • Overview

  • Variants

Overview

  • Determinate when the fraction is known (sprint: 67 of 113 done).
  • Indeterminate for waits with unknown length.
  • Use a spinner for short inline waits.

Anatomy

  1. Label and valueCaption, tabular.
  2. Track7px, --color-border-default.
  3. FillAccent.

Variants

Success, danger, indeterminate.
HTML
<div class="stack" style="width: 18rem;"><div class="progress progress--success" role="progressbar" aria-label="Upload complete" aria-valuenow="100" aria-valuemin="0" aria-valuemax="100" style="--progress-value: 100%;"><div class="progress__bar"></div></div><div class="progress progress--danger" role="progressbar" aria-label="Upload failed" aria-valuenow="40" aria-valuemin="0" aria-valuemax="100" style="--progress-value: 40%;"><div class="progress__bar"></div></div><div class="progress progress--indeterminate" role="progressbar" aria-label="Loading"><div class="progress__bar"></div></div></div>

Sizes

Not applicable: One height (7px); mini variant in hierarchy rows is the same bar at 110px wide.

States

Pointer and focus states are forced with data-state so they can be reviewed statically; product code gets them from real pseudo-classes and attributes.

Value changes animate over --duration-slow.

Both themes

Responsive behaviour

  • Mini progress in epic rows hides below 760px; the percentage text remains.

Theming

Component tokens: --progress-value, --progress-fill. Each aliases a semantic token, so a theme re-colours the component by overriding semantic tokens and a product re-skin overrides the component tokens; neither edits the component CSS.

Accessibility

Role and pattern

role="progressbar" with aria-valuenow/min/max and a label; indeterminate omits aria-valuenow.

Keyboard

KeyAction
—Not focusable.

Focus

Not focusable.

Labelling

Label names what is progressing.

Contrast

Fill vs track
Fill vs surface
Meta text

Motion

The indeterminate sweep stops under reduced motion (the bar stays visible).

Touch

Controls are at least --control-height-md (40px) tall, above the 24px minimum; in dense rows the whole row is also a target and neighbours keep 8px apart.

Content

  • Value text: "59%" or "67 of 113".
