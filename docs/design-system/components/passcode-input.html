Passcode input

Four digit boxes that unlock the shared workspace.

WCAG 2.2 AAStatus: stableProduct component

Overview

  • Only on the passcode screen. The workspace has no user accounts; one passcode opens it.
  • Digits auto-advance; paste fills all boxes.
  • After an incorrect code the row shakes once and an error explains what to do.

Anatomy

  1. Digit box48×56px, mono 22px bold.
  2. Filled boxDefault text border.
  3. Group--space-3 gaps; one label for the set.

Variants

Empty, ready.

Sizes

Not applicable: One size (--control-height-lg wide).

States

Pointer and focus states are forced with data-state so they can be reviewed statically; product code gets them from real pseudo-classes and attributes.

Both themes

  • Invalid shakes once (--duration-deliberate), tints the boxes and shows "That passcode didn't work. Check it and try again."
  • Busy disables the boxes while the code is checked; the unlock button shows its loading state.
  • Too many attempts locks entry and says when to retry.

Responsive behaviour

  • Boxes stay 48px wide down to 320px (4 × 48 + 3 × 12 = 228px).

Theming

The component reads semantic tokens only (listed under Tokens). The dark theme re-maps those tokens; nothing in the component changes.

Accessibility

Role and pattern

role="group" with a label; each box is <input inputmode="numeric" autocomplete="one-time-code"> labelled "Digit n of 4". Errors go to a role="alert" message.

Keyboard

KeyAction
DigitsFills the box and moves to the next.
BackspaceClears and moves back.
← →Moves between boxes.
PasteFills all four.

Focus

The shared ring (--focus-ring-width solid --color-focus-ring, --focus-ring-offset gap) appears on :focus-visible only. The mocks drew a 25% green halo (rgba(39,103,73,.25)) that measured 1.3:1; the system ring is solid and passes 3:1 (drift D2).

Labelling

Group label "Passcode"; each digit box labelled by position.

Motion

The invalid shake is removed under reduced motion; the error message still appears.

Touch

Boxes are 48px wide, above the 44px comfortable target.

Content

  • Error: "That passcode didn't work. Check it and try again."
  • Lockout: "Too many attempts. Try again in 5 minutes."
