Textarea

Multi-line text: story descriptions, acceptance criteria, time-entry notes.

Overview

  • Use for anything that may run past one line.
  • Long-form records (initiative briefs) use the editor's write pane, which is a textarea with a toolbar.

Anatomy

  1. LabelNoun.
  2. Text areaMin 96px tall, resizes vertically.
  3. Counter (optional)Right-aligned, tabular figures.

Sizes

Not applicable: One size; height follows rows (minimum 2).

States

Pointer and focus states are forced with data-state so they can be reviewed statically; product code gets them from real pseudo-classes and attributes.

Both themes

Responsive behaviour

  • Full width of its column; resize handle stays vertical only.

Theming

Component tokens: --field-bg, --field-border. Each aliases a semantic token, so a theme re-colours the component by overriding semantic tokens and a product re-skin overrides the component tokens; neither edits the component CSS.

Accessibility

Role and pattern

Native <textarea> with label; counter linked through aria-describedby and announced politely only near the limit.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterNew line (never submits).

Focus

The shared ring (--focus-ring-width solid --color-focus-ring, --focus-ring-offset gap) appears on :focus-visible only. The mocks drew a 25% green halo (rgba(39,103,73,.25)) that measured 1.3:1; the system ring is solid and passes 3:1 (drift D2).

Labelling

Same as text field.

Motion

No motion beyond colour transitions over --duration-fast, which the tokens zero under prefers-reduced-motion.

Touch

Controls are at least --control-height-md (40px) tall, above the 24px minimum; in dense rows the whole row is also a target and neighbours keep 8px apart.

Content

  • Placeholders ask a question: "What did you work on?".
