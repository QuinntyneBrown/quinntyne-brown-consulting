Navigation and page structure

Shell, page head, breadcrumbs, back links and tabs.

WCAG 2.2 AAStatus: stable
  • Overview
  • When to use
  • Structure
  • States
  • Responsive
  • Accessibility

Overview

  • Four areas in the sidebar; everything else is reached from them.

When to use

  • Sidebar: top-level areas.
  • Breadcrumb: pages below an area (assistant hours).
  • Back link: phones, where the breadcrumb hides.
  • Tabs: sections of one object.

Vanessa

Shell with current nav, breadcrumb, page head.

States

  • Current page: aria-current="page" in sidebar and breadcrumb.

Responsive

  • Sidebar drawer and compact top bar below 760px.

Accessibility

  • Landmarks: banner, navigation (labelled), main; one <h1>; skip link first.

Content

  • Area names are nouns; page titles match nav labels.
