Empty and error states

First-run, no results, failed loads and full-page errors.

Overview

  • Every list has an empty state; every load has an error state.

When to use

  • First run: no stories, no hours, no files.
  • No results: filters or search hide everything.
  • Load failed: show the error as the empty state with Try again.
  • Page missing: error page in the shell.
