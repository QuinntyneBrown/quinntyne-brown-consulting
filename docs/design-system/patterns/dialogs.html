NeedUse

Structure

Remove the attachment?

menu-photos.pdf is removed from QBC-269.

Backdrop + confirmation.

States

  • Never stack more than one dialog; a confirmation inside a form dialog replaces its footer instead.
  • Busy and failed states keep the dialog open.

Responsive

  • Dialogs become bottom sheets below 760px; menus over six items too.

Accessibility

  • Native <dialog> with showModal(); focus in, Esc out, focus back.

Content

  • Title the task; name both choices with verbs.
