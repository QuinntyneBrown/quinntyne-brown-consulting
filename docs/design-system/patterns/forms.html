Pattern

Forms

Story, sprint, assistant and time forms: layout, validation timing, errors and submit states.

WCAG 2.2 AAStatus: stable

  • When to use
  • Structure
  • States
  • Responsive

Overview

  • Forms live in dialogs (story, sprint, assistant, log time) or inline rows (tasks, time entries).

When to use

  • Dialog form: creating or editing one object.
  • Inline row: adding many small items quickly.
  • Editor page: long-form initiative records.

Structure

Fix 1 problem to save the story
  • Enter a title
Enter a title.
Error summary, two-column grid, full-width field, actions bar.

States

  • Pristine: no errors shown.
  • Invalid: validate on blur, re-validate on input once shown; on submit show the summary and focus it.
  • Submitting: primary loading, Cancel disabled.
  • Failed: danger alert in the dialog body, values kept.
  • Saved: dialog closes, toast confirms, focus returns.

Responsive

  • One column below 760px; dialog becomes a sheet.

Accessibility

  • Labels for every control; errors linked via aria-describedby; novalidate with custom messages; summary is role="alert".

Content

  • Labels are nouns; errors are fixes; the submit button repeats the verb of the title.
