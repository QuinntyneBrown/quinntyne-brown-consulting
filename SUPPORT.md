# Support

QBC Workboard is maintained in public on a best-effort basis. GitHub support does
not include a response-time or resolution-time service level.

## Choose a channel

| Request | Channel |
|---|---|
| Reproducible product defect | [Open a bug report](https://github.com/QuinntyneBrown/quinntyne-brown-consulting/issues/new?template=bug_report.md) |
| Product idea or behavior change | [Open a feature request](https://github.com/QuinntyneBrown/quinntyne-brown-consulting/issues/new?template=feature_request.md) |
| Documentation correction | [Open a documentation issue](https://github.com/QuinntyneBrown/quinntyne-brown-consulting/issues/new?template=documentation.md) |
| Setup or usage question | [Open a question](https://github.com/QuinntyneBrown/quinntyne-brown-consulting/issues/new?template=question.md) |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); do not open a public issue |
| Code of Conduct report | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Search [existing issues](https://github.com/QuinntyneBrown/quinntyne-brown-consulting/issues?q=is%3Aissue)
before opening a new one.

## Information to include

A useful support request identifies:

- the commit, branch, or release in use;
- operating system, .NET SDK, Node.js, npm, browser, and SQL Server versions;
- expected and actual behavior;
- the smallest reproducible sequence;
- relevant logs or screenshots with secrets and personal data removed; and
- workarounds already attempted.

Use a minimal sample when the behavior depends on local configuration. Do not
upload a production database or customer workspace.

## Support boundaries

The project currently targets one trusted workspace and a Windows development
environment with SQL Server Express. Authentication, authorization,
multi-tenancy, notifications, comments, attachments, time tracking, and
third-party integrations are outside the requirements baseline.

The public issue tracker covers the repository as published. Custom consulting,
deployment operations, private forks, and bespoke integrations are not included
in community support.
