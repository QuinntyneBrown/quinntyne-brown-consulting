A dropzone with a real, visually hidden file input behind it. `qbc-file-drop` emits `filesSelected` with the chosen `File[]` whether files are dropped or picked with the button, and highlights while files are dragged over it.

Inputs: `variant` (`full`, a tall centred zone, or `compact`, a one-line bar), `heading`, `hint`, `chooseLabel` for the visible picker button, `inputLabel` for the hidden input, and `disabled`.
