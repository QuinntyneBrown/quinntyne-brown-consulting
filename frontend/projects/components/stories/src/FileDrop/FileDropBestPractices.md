## Best practices

### Layout

- Use `full` while a list has no files and switch to `compact` once it does.

### Content

- Use the hint for accepted types and size limits.
- In `compact`, phrase `chooseLabel` to read inside the sentence ("Drop more files or browse").

### Accessibility

- The picker button is keyboard-reachable, so dragging is never the only way to attach.
- Keep `inputLabel` different from `chooseLabel` so two buttons are not announced with the same name.
