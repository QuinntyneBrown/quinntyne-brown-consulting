## Best practices

### Layout

- Use one `primary` button per view or dialog; use `secondary` and `quiet` for the rest.
- Use `full` in narrow containers such as the sign-in form or mobile sheets.

### Content

- Start labels with a verb: "Start sprint", "Add story", "Delete epic".
- Reserve `danger` for destructive actions and confirm them.

### Accessibility

- Set `type="submit"` only on the button that submits a form.
- Set `ariaExpanded` when the button opens or closes a region.
