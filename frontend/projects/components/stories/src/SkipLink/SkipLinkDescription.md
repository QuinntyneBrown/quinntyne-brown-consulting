A visually hidden "skip to content" link for keyboard users. `qbc-skip-link` sits off-screen at the top left and slides into view when it receives focus.

`target` is the id of the element to jump to (default `main-content`) and `label` is the link text (default "Skip to content"). Clicking it focuses the target directly instead of following the `#id` href, so the router never navigates away.
