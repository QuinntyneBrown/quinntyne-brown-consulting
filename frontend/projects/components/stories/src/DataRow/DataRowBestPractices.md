## Best practices

### Layout

- Stack rows directly inside one container; the last row drops its bottom border.
- Keep actions to two or three quiet `sm` buttons.

### Content

- Use the context line for the initiative and epic, separated by " / ".
- Show "Unassigned" in the owner slot rather than leaving it blank.

### Accessibility

- The column labels are only visible on narrow screens, so give the sprint select an `ariaLabel` that names the story when rows repeat.
