## Best practices

### Layout

- Stack rows in a grid with a small gap; each row is its own bordered block.

### Content

- Use `planned`, `active` and `completed` for sprint state so the pill text reads naturally.
- Keep `meta` to one line: dates, story count, story points.
- Offer at most two actions per row.

### Accessibility

- The name is an `h3`; place rows under a section heading of level 2 so the outline stays in order.
- Give icon-only actions an accessible label that includes the sprint name.
