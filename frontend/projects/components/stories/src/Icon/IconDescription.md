A text glyph from the workboard's fixed icon set. `qbc-icon` renders the glyph for `name` (an `IconName`, default `board`) at `size` px (default 16), in a box at least 18px wide so icons line up in lists.

Without a `label` the icon is decorative and hidden from assistive technology; with one it is exposed as `role="img"` with that name.
