## Best practices

### Layout

- Use `padding="none"` when the content brings its own row padding, such as a list of sprints.
- Use `raised` sparingly, for content that sits above the page, not for every panel.

### Content

- Give each card a heading so its purpose is clear at a glance.

### Accessibility

- `interactive` only changes the styling; put a real link or button inside so the card is keyboard reachable.
