A sidebar navigation link. `qbc-nav-item` renders a `routerLink` anchor with a `qbc-icon` and a text `label`; `routerLinkActive` adds the accent `active` style when the current route matches.

Inputs are `href` (required route), `icon` (an `IconName`, default `board`) and `label` (default "Destination"). The `activated` output fires on click so the shell can close the mobile sidebar.
