## Best practices

### Layout

- Use one page header per page, as the first child of `qbc-page`.
- Put the page's primary action last so it sits at the far right.

### Content

- Keep the title short ("Backlog", "Sprint 14"); put context in the description.
- Write the description as one sentence; it is capped at about 650px wide.

### Accessibility

- The title is the page's only `h1`; nest section headings below it.
