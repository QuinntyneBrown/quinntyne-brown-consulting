# Typography

One sans-serif family for everything and a monospace stack for code. The body is set globally in `styles.scss`:

```scss
body {
  color: var(--qbc-ink);
  background: var(--qbc-panel);
  font: 15px/1.5 var(--qbc-font-sans);
}
button,
input,
textarea,
select {
  font: inherit;
}
```

So **15px with a 1.5 line height** is the base, and native controls inherit it rather than falling back to the
browser's control font.

## Font families

`--qbc-font-sans` names Inter first, then the platform UI fonts. No webfont is bundled — Inter renders where it is
installed, and the system stack otherwise.

## Sizes and weights

There is no type-scale token yet: components set sizes and weights literally, on a small, consistent scale. Reuse one of
these steps rather than inventing a new one.

render intermediate weights such as 680 exactly; the system fallbacks round them.
