## Best practices

### Layout

- Use the framed version for a whole page and `bare` inside a container that already has a border.

### Content

- Title what is missing ("No active sprint"), then say how to fix it in one sentence.
- Offer the one action that fills the space; add a second only if it is a real alternative.

### Accessibility

- The title renders as an `h2`; avoid placing it where that breaks the page heading order.
